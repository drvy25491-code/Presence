# Приложение AttendanceControl

## О проекте
Мобильное Android-приложение для преподавателей и кураторов учебных групп колледжа.

**Стек технологий:** Kotlin, Android Studio, XML (View-based), Room (SQLite), Git.
**Основной пользователь** - преподаватель или куратор учебной группы.
## Главный экран
* главный экран имеет 4 кнопки
* `Создать студента`, `Отметить посещаемость`, `Проверить статистику`, `Создать группу`

## Раздел «Студенты» (`StudentsActivity`)

Экран открывается при нажатии на кнопку **«Студенты»** в главном меню и предназначен для управления списком учащихся. В ней можно создать нового студента.

### Что реализовано внутри нее:
* **Форма добавления:** три текстовых поля `Фамилия`, `Имя`, `Группа` и кнопка **«Добавить студента»**.
* **Проверка ввода:** система не даёт сохранить пустые поля, игнорирует ввод одних пробелов и блокирует добавление дубликатов.
* **Список студентов:** отображает всех добавленных учащихся в формате *«Фамилия Имя — Группа»*. Если записей пока нет, на экране выводится подсказка о том, что список пуст.
* **Удаление записи:** при нажатии на студента появляется диалоговое окно с запросом подтверждения («Удалить» или «Отмена»). После подтверждения запись удаляется из списка.

### Системные уведомления:
* При успешном добавлении: *«Студент успешно добавлен»*
* При незаполненных полях: *«Ошибка: заполните фамилию, имя и группу»*
* При попытке добавить дубликат: *«Такой студент уже есть в этой группе»*
* После удаления: *«Студент удалён»*

## Запуск проекта
1. Склонируйте репозиторий и откройте проект в **Android Studio**.
2. Дождитесь завершения синхронизации **Gradle**.
3. Запустите приложение на эмуляторе или Android-устройстве с минимум Android 7.0 и API 24.
