# Приложение AttendanceControl

## О проекте
**AttendanceControl** - мобильное Android-приложение для преподавателей или кураторов учебных групп колледжа, предназначенное для локального учёта посещаемости студентов.

**Стек:**
* **Язык:** Kotlin
* **Среда разработки:** Android Studio
* **Интерфейс:** XML
* **База данных:** Room

## Описание экранов и функционала

### 1. Главный экран
Содержит 4 основные кнопки навигации по разделам системы:
* **«Студенты»** - создание и управление списком студентов.
* **«Отметить посещаемость»** - настройка и создание занятия.
* **«Статистика»** - просмотр истории и подсчёт посещаемости с фильтрами.
* **«Создать группу»** - управление и создание групп.

### 2. Экран Студенты
* **Форма добавления:** поля `Фамилия`, `Имя`, выпадающий список (`Spinner`) для выбора учебной группы и кнопка **«Добавить студента»**.
* **Проверка ввода:** блокировка пустых полей и строк из пробелов.
* **Список студентов:** отображается в `RecyclerView` в формате `«Фамилия Имя (Группа)»`.
* **Удаление записи:** кнопка **Удалить** рядом со студентом вызывает окно подтверждения **Удаления студента**.

### 3. Экран Занятия и отметка посещаемости
* **Настройка занятия:** выбор группы из `Spinner`, ввод названия предмета и даты, кнопка **Перейти к списку студентов**.
* **Список созданных занятий:** все созданные пары сохраняются в БД; нажатие на занятие открывает ведомость для просмотра или повторного редактирования, кнопка **Удалить** удаляет занятие вместе с его отметками.
* **Отметка посещаемости:** для каждого студента выбранной группы доступны три радиокнопки: **Был** или же Присутствовал, **«Не был»** или же Отсутствовал и **Опоздал**. Если в группе нет студентов, выводится соответствующее предупреждение.

### 4. Экран Статистика
* **Показатели:** автоматический подсчёт количества проведённых занятий, присутствий, пропусков и опозданий.
* **Фильтрация:** фильтрация данных по учебной группе, конкретному студенту и дате.
* **История:** при отсутствии совпадений выводится сообщение **Отметок по выбранным фильтрам нет**.

### 5. Экран Группы
* Поле ввода названия группы и кнопки выбора группы, открывается окно для заполнения отметок посещаемости.
* **Валидация:** запрет на создание пустых групп, групп из одних пробелов и дубликатов названий.

## Краткая инструкция пользователя
1. **Создайте группу:** на главном экране нажмите **Создать группу**, введите название (например, `2-ИП-4-25`) и нажмите **Создать группу**.
2. **Добавьте студентов:** перейдите в раздел **Студенты**, введите фамилию и имя, выберите группу из списка и нажмите **Добавить студента**.
3. **Проведите перекличку:** на главном экране нажмите **Отметить посещаемость**, выберите группу, укажите предмет и дату, нажмите **Перейти к списку студентов**. Отметьте статус каждого студента и нажмите **Сохранить**.
4. **Посмотрите статистику:** откройте раздел **Статистика**, при необходимости выберите группу, студента или дату и нажмите **Найти**.

## Как запустить проект
1. Найдите Zip-файл проекта AttendanceControl.
2. Нажмите на него и распакуйте в любой созданной вами папке.
3. Откройте Android Studio
4. Нажмите на Open и на рабочем экране найдити папку в которой находится проект и откройте проект в нём.
5. Дождитесь полного завершения открытия приложения(до зелёного треугольника)
6. Запустите приложение на эмуляторе, нажав на зелёный треугольник.
