## Отчёт
### PO

#### 1. Данные сохраняются в Room
В классе `AppDatabase` сохраняются все сущности, необходимые для работы приложения между перезапусками:
* **Учебные группы (`groups`):** название группы.
* **Студенты (`students`):** имя, фамилия и привязка к группе.
* **Занятия (`lessons`):** группа, дата проведения и название предмета.
* **Отметки посещаемости (`attendance`):** ID студента, дата занятия, предмет и выбранный статус (`"Присутствовал"`, `"Отсутствовал"`, `"Опоздал"`).

#### 2. Согласованные сущности БД (Entities)
* **`GroupEntity` (таблица `groups`):** `id` (PK), `name` (`String`).
* **`StudentEntity` (таблица `students`):** `id` (PK), `firstName` (`String`), `lastName` (`String`), `groupName` (`String`).
* **`LessonEntity` (таблица `lessons`):** `id` (PK), `groupName` (`String`), `lessonDate` (`String`), `subject` (`String`).
* **`AttendanceEntity` (таблица `attendance`):** `id` (PK), `studentId` (`Int`), `lessonDate` (`String`), `subject` (`String`), `status` (`String`).

---

#### 3. Поведение при первом запуске и пустой базе данных
* **Главный экран (`MainActivity`):** открывается без ошибок, доступны переходы во все разделы («Студенты», «Отметить посещаемость», «Создать группу», «Статистика»).
* **Пустая база при попытке создать студента (`StudentsActivity`):** выпадающий список групп (`spinnerGroups`) пуст; при нажатии «Добавить» срабатывает защита и выводится `Toast`: *«Сначала создайте хотя бы одну группу!»*.
* **Пустая база при попытке начать занятие (`LessonSetupActivity`):** список групп пуст, дата подставляется текущая по умолчанию; при нажатии «Начать» без группы выводится `Toast`: *«Сначала создайте группу!»*.
* **Группа без студентов (`AttendanceActivity`):** при открытии занятия для пустой группы список (`rvAttendance`) и кнопка «Сохранить» скрываются, отображается текстовая заглушка `tvEmptyList`.
* **Сохранность и целостность данных:**
  * При повторном сохранении того же занятия старые отметки перезаписываются без дубликатов (`deleteByLesson` -> `insert`).
  * При удалении занятия из истории (`LessonSetupActivity`) связанные с ним отметки посещаемости также удаляются из БД.

---

#### 4. Критерии приёмки PO (сверка результата)
1. **Цепочка «Группа -> Студент»:** Созданная в `GroupsActivity` группа сохраняется в БД, после перезапуска доступна в `StudentsActivity`, а добавленный в неё студент сохраняется в списке.
2. **Цепочка «Занятие -> Посещаемость»:** Созданное в `LessonSetupActivity` занятие отображается в списке ниже; проставленные статусы в `AttendanceActivity` сохраняются и подтягиваются при повторном открытии этого занятия даже после перезапуска приложения.
3. **Удаление данных:** Удаление группы, студента или занятия через диалог подтверждения удаляет запись из Room навсегда (после перезапуска она не возвращается).
