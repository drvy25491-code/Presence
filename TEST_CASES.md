# Тест-кейсы

## 1 спринт 

| Кейс | Сценарий | Результат |
| :--- | :--- | :--- |
| **Тест №1** <br> Запуск приложения | Открыть приложение | Приложение запускается |
| **Тест №2** <br> Главный экран | Открыть главный экран, проверить читаемость | Главный экран виден, всё читабельно |
| **Тест №3** <br> Работа кнопок | Понажимать на все кнопки | Кнопки нажимаются, всплывает toast-уведомление «заглушка» |


## 2 спринт

| Кейс | Сценарий | Результат |
| :--- | :--- | :--- |
| **Тест №4** <br> Корректная запись | 1. Открыть экран студентов.<br>2. Ввести в поле «Фамилия» - `Иванов`, в поле «Имя» - `Иван`.<br>3. Нажать кнопку «Добавить студента». | Студент «Иванов Иван» появляется в списке ниже. Появляется уведомление «Студент добавлен». Поля ввода очищаются. |
| **Тест №5** <br> Пустые поля | 1. Открыть экран студентов.<br>2. Оставить оба поля пустыми.<br>3. Нажать кнопку «Добавить студента». | Внизу экрана появляется всплывающее уведомление: «Заполните Фамилию и Имя!». Запись в список не добавляется. |
| **Тест №6** <br> Пробелы вместо текста | 1. Открыть экран студентов.<br>2. Ввести в оба поля несколько пробелов.<br>3. Нажать кнопку «Добавить студента». | Система обрабатывает пробелы как пустую строку. Появляется уведомление «Заполните Фамилию и Имя!». Запись не добавляется. |
| **Тест №7** <br> Повторная запись (Дублировать) | 1. Добавить студента «Иванов Иван».<br>2. Снова ввести «Иванов Иван» и нажать «Добавить». | Второй студент с такими же ФИО успешно добавляется в список (на данный момент дубликаты разрешены, так как нет проверки на уникальность). |
| **Тест №8** <br> Удаление (с подтверждением) | 1. В списке студентов нажать кнопку «Удалить» рядом со студентом.<br>2. В появившемся диалоговом окне нажать «Отмена».<br>3. Снова нажать «Удалить» и выбрать «Удалить». | **Шаг 2:** Диалог закрывается, студент остается в списке.<br>**Шаг 3:** Студент исчезает из списка. |
| **Тест №9** <br> Проверка сборки (Сборка после добавления файлов) | 1. Добавить в проект файлы `Student.kt`, `StudentsActivity.kt`, `activity_students.xml`.<br>2. Нажать «Build» -> «Make Project». | Внизу в панели Build появляется сообщение **`BUILD SUCCESSFUL`**. Тогда ошибок компиляции не будет. |


## 3 спринт 

| Кейс | Сценарий | Результат |
| :--- | :--- | :--- |
| **Тест №1** <br> Настройка занятия и валидация | Попытаться начать занятие с пустыми полями, затем ввести группу, предмет и дату | При пустых полях появляется toast «Заполните все поля занятия!», при заполнении открывается экран отметки |
| **Тест №2** <br> Список студентов и все статусы | Открыть занятие для группы с несколькими студентами и выбрать статусы «Присутствовал», «Отсутствовал», «Опоздал» | Отображаются все студенты группы; по умолчанию стоит «Присутствовал», все 3 статуса корректно выбираются |
| **Тест №3** <br> Изменение статуса и сохранение | Изменить статус студента до сохранения на «Опоздал» и нажать кнопку «Сохранить» | Фиксируется последний выбранный статус, появляется toast «Посещаемость сохранена!», экран закрывается |
| **Тест №4** <br> Повторная отметка | Повторно открыть то же самое занятие, поменять отметку и сохранить заново | Подтягиваются прошлые статусы; после сохранения старая запись перезаписывается без дубликатов |
| **Тест №5** <br> Пустой список студентов | Ввести группу без студентов и перейти к отметке посещаемости | Список студентов и кнопка сохранения скрыты, отображается сообщение о пустом списке |
