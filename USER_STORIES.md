User Stories и Критерии приёмки
№1
User Stories: Как преподаватель, я хочу видеть в программе возможность отмечать  присутствие, отсутствие и опоздание студентов, чтобы можно было понять всю посещаемость студентов.

Критерии приёмки: На экране занятия для каждого студента из списка группы доступны три кнопки: Присутствовал, Отсутствовал, Опоздал.

Все проставленные статусы сохраняются в локальную базу данных Room

№2
User Stories: Как преподаватель, я хочу создавать и просматривать список учебных групп, чтобы структурировать студентов по их потокам и специальностям.

Критерии приёмки: В приложении есть экран со списком всех добавленных учебных групп, в котором показаны студенты

№3
User Stories: Как преподаватель, я хочу видеть статистику посещаемости студента.

Критерии приёмки: На экране статистики отображается общее количество занятий, а также число присутствий, опозданий и пропусков.
Статистика автоматически пересчитывается при добавлении новых занятий или изменении статусов в базе данных.

№4
User Stories: Как куратор, я хочу добавлять студентов в учебную группу с указанием фамилии и имени, чтобы формировать актуальный список для переклички.

Критерии приёмки: Внутри выбранной группы доступна форма добавления нового студента.
Система не позволяет сохранить студента, если поля Фамилия или Имя не заполнены.
Реализована возможность удалить или отредактировать данные студента.

№5
User Stories: Как преподаватель, я хочу создавать карточку занятия с указанием даты, дисциплины и темы, чтобы привязывать отметки посещаемости к конкретной паре.

Критерии приёмки: Доступна форма создания занятия с выбором учебной группы, даты проведения, названия дисциплины и темы урока.

№6
User Stories: Как преподаватель, я хочу просматривать историю проведённых занятий и отметок посещаемости по ним, чтобы при необходимости проверять прошлые записи.

Критерии приёмки: При выборе конкретного занятия открывается ведомость с ранее выставленными статусами и комментариями.
